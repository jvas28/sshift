Privacy Policy

Last updated: September 23, 2026

sshift is a desktop application for Windows that manages OpenSSH connection profiles on your computer.

Data sshift handles

  • SSH profiles (aliases, host names, user names, ports, identity file paths, connection options, display names, tags and notes) are stored only on your computer: in the app's local data folder and in %USERPROFILE%\.ssh\sshift\config.
  • SSH keys: sshift reads public keys (.pub files) to show their fingerprints. It never reads, copies or uploads the contents of private keys.
  • Passwords and passphrases are never stored. When you generate a key, the passphrase is passed directly to ssh-keygen and discarded.
  • Logs are written locally, kept for at most 7 days or 10 MB, and never include passwords, passphrases or key contents.

Data sharing

sshift has no telemetry, analytics, advertising or crash reporting, and it does not send any data to the developer or to third parties.

sshift only connects to the network when you ask it to:

  • Connect and Test authentication run the Windows OpenSSH client (ssh.exe) against the server you selected.
  • Check network opens a TCP connection to the host and port of the selected profile.

Microsoft Store

sshift uses the Microsoft Store to check whether you are using the free trial or the full version, and to process purchases. This information is handled by Microsoft under the Microsoft Privacy Statement. sshift does not receive your payment details.

Your control

All data stays on your computer. Uninstalling sshift removes its local data folder. Your SSH configuration (%USERPROFILE%\.ssh) and your keys are never deleted by sshift.
